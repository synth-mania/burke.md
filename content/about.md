# about

Burke. I own this domain because it's the most honest way to describe what this site is:
a handful of markdown files, styled but never hidden.

## principles

- **plain text first** — the source is the site
- **visible syntax** — the markup that makes the page should be *in* the page
- **no JavaScript** on rendered pages; a post-commit hook does the work
- **raw link on everything** — [example: this page's source](/about.md)

## what this is not

It's not a blog platform, a CMS, or a framework. It's a directory of `.md`
files and a build script, which is to say it's a website the way a shell
script is a program.
