# it is live

`burke.md` went live today on its own domain. the idea in one line: the
pages are markdown files, and the rendered pages keep the markdown — the
`#`, the `**`, the `[text](url)` — styled, but never hidden.

## how this post got here

- write a file in `content/posts/`, named `YYYY-MM-DD-slug.md`
- commit and push
- the build renders the page, updates the [index](/posts), and regenerates
  [the feed](/feed.xml)

if you are reading this in a feed reader: you have [the atom feed](/feed.xml),
and every entry links to the [raw markdown](/posts/2026-09-02-it-is-live.md)
it was built from.
